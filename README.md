# مزایده دامنه sorati.ir

یک سایت تک‌صفحه‌ای فارسی و واکنش‌گرا با PHP و MySQL برای دریافت و مقایسه پیشنهاد قیمت فروش دامنه **sorati.ir**.

## امکانات

- رابط فارسی راست‌چین با طیف آبی و سفید و طراحی واکنش‌گرا.
- فرم ثبت نام و نام خانوادگی، موبایل، قیمت پیشنهادی، توضیحات اختیاری و ایمیل اختیاری.
- اعتبارسنجی سمت سرور، تبدیل ارقام فارسی/عربی، کپچای جمع ساده، توکن CSRF و فیلد ضدربات.
- ذخیره تمام پیشنهادها در MySQL و نمایش حداکثر ۱۰ پیشنهاد ثبت‌شدهٔ اخیر در جدول رتبه‌بندی‌شده بر اساس قیمت نزولی.
- نمایش شماره ردیف، قیمت پیشنهادی و موبایل ماسک‌شده (چهار رقم اول و دو رقم آخر قابل مشاهده است).
- پیام تأیید به کاربر و پیام جداگانهٔ مدیر فقط با پترن‌های تأییدشدهٔ خدماتی/اشتراکی ملی‌پیامک.
- شمارشگر زندهٔ پایان مزایده بر پایهٔ مدت و زمان شروع ثابت قابل تنظیم در `config.php`.
- ثبت وضعیت و شناسه پاسخ پیامک در دیتابیس؛ ستون `user_sms_sent` برای پیامک کاربر مقدار `1` (ارسال‌شده) یا `0` (ارسال‌نشده) دارد. خطای ارسال پیامک کاربر در صفحه نمایش داده نمی‌شود.

## نیازمندی‌ها

- PHP 8.1 یا بالاتر با افزونه‌های `pdo_mysql`, `curl`, `mbstring`, `openssl`.
- MySQL 8.0+ یا MariaDB سازگار.
- دامنه و وب‌سرور Apache/Nginx با HTTPS توصیه‌شده.

## نصب

1. فایل‌های پروژه را روی هاست قرار دهید و ریشه وب‌سایت را به پوشه پروژه تنظیم کنید.
2. از پنل هاست (مثلاً بخش MySQL Databases در cPanel) یک دیتابیس بسازید و کاربر MySQL را به آن متصل کنید. سپس در phpMyAdmin همان دیتابیس را از ستون کناری انتخاب و فایل `database.sql` را در همان دیتابیس Import کنید. فایل SQL فقط جدول `bids` را می‌سازد و عمداً دستور `CREATE DATABASE` یا `USE` ندارد؛ بنابراین به مجوز ساخت دیتابیس نیاز نیست.
   - اگر سایت قبلاً نصب شده و جدول `bids` را دارد، به‌جای import دوبارهٔ فایل اصلی، فایل `migration_add_user_sms_sent.sql` را یک‌بار روی همان دیتابیس اجرا کنید تا ستون جدید اضافه شود و وضعیت‌های قبلی نیز منتقل شوند.
3. در `config.php`، نام دقیق دیتابیس ساخته‌شده در پنل هاست (با پیشوند احتمالی)، میزبان، نام کاربر و رمز عبور MySQL را وارد کنید. نام دیتابیس و کاربر ممکن است در هاست اشتراکی پیشوند حساب داشته باشند.
4. در پنل ملی‌پیامک، دسترسی وب‌سرویس خدماتی/اشتراکی را برای حساب فعال کنید و دو پترن تأییدشده بسازید: پترن کاربر با `{0}=نام` و پترن مدیر با `{0}=نام` و `{1}=شماره موبایل کاربر`.
5. `sms.username`، `sms.api_key`، شماره مدیر، `user_pattern_id` و `admin_pattern_id` را در `config.php` وارد کنید. پترن مدیر فقط پس از پذیرش پیامک کاربر ارسال می‌شود. در این پروژه API Key به‌جای رمز پنل برای اعتبار وب‌سرویس استفاده می‌شود؛ رمز ورود پنل را در تنظیمات سایت قرار ندهید.
6. در بخش `auction`، مقدار `duration_days` را به تعداد روزهای مزایده و `start_at` را به زمان شروع آن با منطقه زمانی تهران تنظیم کنید. زمان شروع باید ثابت بماند تا شمارشگر با هر بار بارگذاری صفحه از نو آغاز نشود؛ پایان مزایده برابر شروع به‌علاوهٔ تعداد روزهاست.
7. در پایان HTTPS را فعال کنید و دسترسی نوشتن به فایل‌های PHP را برای وب‌سرور لازم نکنید.

## الگوهای پیامک پیشنهادی

پیام کاربر از `user_pattern_id` و یک متغیر `{0}=نام و نام خانوادگی` استفاده می‌کند. پس از پذیرش این پیام توسط سرویس، پیام مستقل مدیر از `admin_pattern_id` با دو متغیر مرتب `{0}=نام و نام خانوادگی` و `{1}=شماره موبایل` ارسال می‌شود. ارسال با خط تبلیغاتی/متن آزاد در این پروژه پیاده‌سازی نشده است.

## اتصال ملی‌پیامک

کد از REST endpoint `https://rest.payamak-panel.com/api/SendSMS/BaseServiceNumber` و روش `SendByBaseNumber` استفاده می‌کند. تنظیمات پروژه جداگانه `username` و `api_key` هستند؛ درخواست شامل نام کاربری و API Key به‌عنوان رمز وب‌سرویس است و از رمز ورود پنل استفاده نمی‌کند. اگر سرویس حساب شما API Key را با قرارداد یا فیلد دیگری می‌پذیرد، نمونه‌کد دقیق ارائه‌شده در پنل/کنسول ملی‌پیامک باید مبنای تغییر adapter `sendPatternSms()` باشد. TLS verification روشن است.

## حریم خصوصی و نمایش عمومی

فهرست عمومی فقط ۱۰ پیشنهاد اخیر را نشان می‌دهد؛ ابتدا ۱۰ رکورد جدید بر اساس زمان ثبت انتخاب می‌شوند و سپس همان‌ها از بالاترین قیمت به پایین‌ترین مرتب می‌شوند. جدول شامل ردیف، مبلغ و شمارهٔ ماسک‌شده است؛ نام، ایمیل و توضیحات عمومی نیستند. با این حال مبلغ پیشنهادها علنی است. پیش از راه‌اندازی، متن رضایت/اطلاع‌رسانی و رویه نگهداری داده را با شرایط کسب‌وکار خودتان تطبیق دهید.

## تست

- پس از پیکربندی، با یک پیشنهاد آزمایشی ثبت دیتابیس، ماسک شماره، ترتیب قیمت و وضعیت ارسال پیامک را کنترل کنید.
- برای جلوگیری از ارسال واقعی پیامک، در محیط توسعه شناسه الگو را صفر بگذارید؛ ثبت پیشنهاد همچنان انجام می‌شود و خطای عدم پیکربندی در لاگ سرور ثبت می‌شود.
- لاگ PHP/وب‌سرور را فقط مدیر سرور مشاهده کند.

## فایل‌ها

- `index.php` — صفحه واحد و تمام منطق فرم، دیتابیس و ارسال پترن.
- `config.php` — تنظیمات قابل تغییر پایگاه داده و ملی‌پیامک؛ حتماً مقادیر نمونه را پیش از انتشار تغییر دهید.
- `style.css` — رنگ‌بندی آبی‌وسفید، استایل شمارشگر و واکنش‌گرایی.
- `database.sql` — ساخت جدول پیشنهادها در دیتابیس انتخاب‌شده.
- `.htaccess` — جلوگیری از دسترسی مستقیم به فایل تنظیمات و SQL در Apache.
